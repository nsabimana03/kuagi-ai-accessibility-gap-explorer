# KUAGI AI Accessibility Gap Explorer

## Map<>Kathon 2026 Project

KUAGI (Kigali Urban Accessibility Gap Index) is an AI-powered GIS dashboard designed to identify and visualize accessibility gaps across Kigali City, Rwanda.

## Problem

Urban communities experience unequal access to essential services such as:

- Schools
- Health facilities
- Markets
- Public transport
- Roads

KUAGI helps identify priority areas where improvements are needed.

## Solution

The project combines:

- OpenStreetMap data
- GIS spatial analysis
- Accessibility indicators
- Population information
- AI-assisted recommendations

to support evidence-based urban planning.

## Main Features

✅ Interactive ArcGIS Dashboard  
✅ District and sector filtering  
✅ Gap priority classification  
✅ KUAGI score visualization  
✅ AI-generated actions and explanations  

## OSM Data Used

OpenStreetMap features:

- Roads
- Schools
- Health facilities
- Markets
- Transport locations
- Urban features
